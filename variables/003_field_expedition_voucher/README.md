# Field Expedition Expense Voucher

## Problem
A reasearch team has returned from an environmental field expedition. A researcher needs to prepare an expense voucher showing how much money was spent and how much of the original budget remains.

## Objective
Build a small program that displays a readable expense report.

## Specifications

Expedition records:
|Expense item       |                Amount|
|-------------------|----------------------|
|Transport          |               R850.00|
|Food and supplies  |               R425.50|
|Research materials |               R310.00|
|Original budget    |              R2000.00|

- Store each expense and the original budget.
- Calculate the total expenses.
- Calculate the remaining budget.
- Display an expense voucher with the individual expenses, total spent, orignal budget, and remaining balance.
- Format the monetary amounts to two decimal places

## Concepts Practised
- Variables, assignment, and data types
- print() and f-strings
- Reassignment and execution order
- Arithmetic operators and expressions
- Storing and reusing calculated results
- Numeric formatting with .2f
