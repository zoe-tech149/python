# Medical Temperature Tracker

A beginner Python program that stores patient information in variables and displays it in a readable medical report.

## Overview

The Medical Temperature Tracker demonstrates how Python variables can store and reuse information throughout a program.

The program records a patient's name, age, and temperature, then displays those details in a formatted sentence using an f-string.

## Example Output

```text
Patient Lisa is 24 years old and has a temperature of 38.4°C.
```

## Concepts Practised

- **Variables and assignment** — assigning information to names.
- **Name binding** — binding names to Python objects.
- **Naming conventions** — using uppercase names for values intended to remain constant.
- **Data types** — working with strings and integers.
- **F-strings** — inserting variable values into formatted output.
- **`print()`** — displaying information in the terminal.

## How to Run

**Requirements:** Python 3 installed on your computer.

1. Open a terminal in the project directory.
2. Run the following command:

```bash
python main.py
```

Depending on your Python installation, you may need to use `python3 main.py` instead.

## Learning Objective

The goal of this project is to understand how variables allow a program to store information under meaningful names and reuse that information when producing output.

## Scope

This is a foundational command-line exercise. It uses predefined patient information and does not yet accept user input, validate medical measurements, or perform medical assessments.
