# Arctic Research Station Status

## Problem
A researcher has recorded the latest station conditions. Currently, the information i scattered across their notes. A console report is needed to show the station's identity, current environmental readings, and equipment status.

## Objective
Build a program that displays the information in a clean, readable format.

## Specifications
- Represent the station name as text
- Represent temperature and wind as numerical readings
- Represent battery level as a whole-number percentage
- Represent whether the emergency beacon is active as a true/false value
- Display all five pieces of information in a readable report
